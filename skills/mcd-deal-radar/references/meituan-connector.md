# 美团生活助手 Connector 接入说明（参考）

> 来源：WorkBuddy 连接器中心生态内「美团生活助手」（当前默认 **未连接**）。
> 知识截止 2026-10-12 联网核验。具体工具名 / 参数以连接器实际暴露接口为准，标 `[INFO_GAP]`。

## 这是什么
「美团生活助手」是 WorkBuddy 生态内的连接器 / 专家，能力包含「一键领取美团优惠券」「搜索附近团购美食并下单」。本包用它作为**美团渠道**的麦当劳团购券数据源。

## 接入步骤
1. 打开 WorkBuddy → 连接器中心 → 搜索「美团生活助手」。
2. 点击连接并**完成美团账号授权**（OAuth，授权后 token 由系统托管，本包不接触明文）。
3. 在 Skill 中通过连接器调用其「查询麦当劳团购券」能力 `[INFO_GAP]`。

## 本包用法
- 在 `SKILL.md` 工作流第 1 步，与麦当劳 MCP **并行**调用美团生活助手。
- 返回数据经 `scripts/aggregate.py` 的 `normalize(channel="美团", ...)` 拉平后参与比价。

## 边界
- 美团优惠为城市/门店级，需传入用户位置 `[INFO_GAP]`。
- 仅用连接器授权范围内的公开团购数据，不爬私有页。
- 若连接器接口变更，以 WorkBuddy 连接器中心最新文档为准。
