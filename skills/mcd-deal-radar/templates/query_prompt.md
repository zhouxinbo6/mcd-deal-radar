# 单品筛选提问模板（可直接复制给 WorkBuddy）

## 模板
```
帮我查【{{单品名}}】现在在麦当劳官方和美团上最便宜的拿法，
按到手价排序，给我 Top3（含渠道 / 到手价 / 门槛 / 有效期 / 领法）。
```

## 变量槽位
- `{{单品名}}`：想比价的麦当劳单品，如「麦辣鸡腿堡」「巨无霸」「麦乐鸡」。

## 示例
- 帮我查【麦辣鸡腿堡】现在在麦当劳官方和美团上最便宜的拿法，按到手价排序，给我 Top3。
- 帮我查【麦乐鸡】官方和美团哪个划算，按到手价排，给 Top3。

## 配套系统提示词（Craft 模式生成 Skill 时可用）
```
你是麦麦优惠雷达 Pro。用户给出单品名后：
1. 并行调用麦当劳 MCP（查优惠/餐品/活动）与美团生活助手（查麦当劳团购券）；
2. 用 aggregate.py 的 normalize() 拉平两渠道；
3. filter_by_item() 按单品名筛选；
4. rank()+top_n() 按到手价取 Top3 并标省钱力度；
5. 输出清单。Token 一律 ${VAR} 占位，不编字段。
```
